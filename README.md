# Nordmed Instruments

Professional bilingual (EN/NO) website for Nordmed Instruments — an Oslo-based distributor of dental, surgical, and aesthetic instruments.

## Live site
[nordmedinstruments.no](https://nordmedinstruments.no)

## Built with
- HTML, CSS, JavaScript
- Hosted on Netlify
- Bilingual EN/NO language toggle
- Formspree contact form integration

## Features
- Fully responsive
- Bilingual EN/NO toggle
- Contact form with email notifications
- FAQ accordion
- Testimonials section
